# 2026-11-25: Super Mario 3D Land, V-Sync on versus off, both displays on, build 0.1.2

Evidence: **device test** by the project owner, build `753f9a6`, 60 Hz, Turnip, warm cache.
Figures are for steady gameplay after the first 15 s.

| Measure | V-Sync on (21:25:33, 55 s) | V-Sync off (21:26:53, 45 s) |
| --- | --- | --- |
| Present mode | FIFO | MAILBOX |
| Frames submitted per second | 59.73 | 59.83 |
| Emulated frames per second | 59.84 | 59.86 |
| Display cadence | every reported image exactly one refresh after the previous one | every image held one refresh |
| Frames never shown | none observed (see note) | 3 of 1,773 (0.2%) |
| Median submit-to-display delay | 93 ms | 45 ms |
| Time waiting in the present queue, median | 30 ms | 0.6 ms |
| Image acquire, median | 15 ms | 0.1 ms |
| Emulation thread waiting for a free frame, mean | 1.6 ms per frame | 0.08 ms per frame |

Note on V-Sync on: display reports came back for only half of the frames, in a strict
two-reported, two-missing pattern matching the four-present polling interval. The reported
display times sit on consecutive refreshes with exactly two refresh periods across each
gap, so the missing reports are frames that were shown but whose report was lost. This is
a logging fault, fixed in 0.1.3.

## Findings

1. V-Sync on gives one new image per refresh on both screens, at about twice the
   submit-to-display delay (93 ms against 45 ms). The delay comes from images queueing:
   the swapchain has 6 images and frames wait a median of 30 ms before being presented.
2. V-Sync off with both displays on lost only 0.2% of frames in this run, the same as the
   earlier bottom-off run. The 7.9% loss seen at 20:00:22 with both displays on was **not
   reproduced**. Having the bottom display on is therefore not sufficient to cause it.
3. What differed in the 20:00:22 run is not established. In that run the bottom panel had
   just been switched back on with the hardware button, the submit-to-display delay was one
   refresh longer (59 ms), and losses came in bursts once per 10 s beat between 59.84 and
   59.73 Hz.
